# Kaijan — production

Version: 0.5.0-bundle.4. Platform: macOS ARM64.

## Install

In Workspace Admin, import the GitHub source `https://github.com/katalon-studio/kaijan-marketplace`. Leave Path empty and set the branch to `workspace/kaijan-prod-bundled`. The root catalog contains the production plugin.

## Trial

Run Kaijan Connect with your own account. Service eligibility and limits are controlled by the Kaijan service; this repository does not grant a trial entitlement. QA is a preview environment. Do not use company credentials shared by another user.

## Package

This package contains the distributed plugin and third-party notices. Source history and internal build reports are not included. Node is prepared with an ad-hoc signature; this preview is not a notarized Production installer.
