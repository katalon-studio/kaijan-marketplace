JSON parser compatibility

The JSON scanner and diagnostic grammar in json.mjs follow CPython3.9.6's Modules/_json.c and Lib/json/decoder.py, and json.loads string BOM handling from Lib/json/__init__.py.

The Node translation retains this package's existing source_invalid_JSON failure code and adds a versioned diagnostic payload. It is not a runtime Python dependency.
