# Kaijan for Claude

Install from katalon-studio/kaijan-marketplace, then install kaijan@kaijan-claude.

Start CLI with KAIJAN_PROFILE=qa for QA, or unset for Production. Restart the session's plugin processes after switching. Use /kaijan:setup, /kaijan:demo for a real TodoMVC test, and /kaijan:mod-demo for a simulated UI showcase.

This replaces the old kaijan-qa/kaijan preview split. Use normal uninstall controls for the old preview aliases and remove their kaijan-claude-preview marketplace registration before adding the Git repository as kaijan-claude. Existing saved data and grants are preserved.
