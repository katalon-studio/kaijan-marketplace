Unicode word data derived from UnicodeData.txt 13.0.0 and 15.0.0.
Copyright (c) 1991-2026 Unicode, Inc. License: UNICODE-LICENSE.txt.
Upstream URLs and exact SHA-256 hashes are embedded in each generated JSON file.

Modification: retain only CPython alphanumeric membership plus U+005F as sorted,
inclusive codepoint ranges. Numeric Unihan ideographs are already letters.
Reproduce with Node, supplying the exact upstream files in version order:
node build-unicode-word-data.mjs UnicodeData-13.0.0.txt UnicodeData-15.0.0.txt
The generator checks both source hashes and performs no network requests.

Definition sources (PSF license: PYTHON-LICENSE.txt):
https://github.com/python/cpython/blob/v3.9.6/Modules/_sre.c
https://github.com/python/cpython/blob/v3.12.14/Modules/_sre/sre.c
SRE_UNI_IS_WORD is Py_UNICODE_ISALNUM or underscore.
https://github.com/python/cpython/blob/v3.9.6/Include/cpython/unicodeobject.h
https://github.com/python/cpython/blob/v3.12.14/Include/cpython/unicodeobject.h
Py_UNICODE_ISALNUM is alpha, decimal, digit or numeric.
https://github.com/python/cpython/blob/v3.9.6/Tools/unicode/makeunicodedata.py
https://github.com/python/cpython/blob/v3.12.14/Tools/unicode/makeunicodedata.py
Alpha is general category Lu, Ll, Lt, Lm or Lo; numeric flags use UCD fields.

Fixed bindings: python3.9.6 -> Unicode13.0.0; python3.12.14 -> Unicode15.0.0.
Only this word-boundary predicate is supplied here. URL parser and JSON codec
retain their separate documented compatibility scope. No ambient Unicode test
or runtime interpreter is used.
