# Kaijan icon

`kaijan-ready.png` is the unchanged 512 × 512 static `ready` export from
[the approved Kaijan mascot](../../../../design/kaijan-mascot/README.md), selected
by Minh Tran on 27 October 2026 and merged in PR #2103. It is used in the Codex
plugin logo and composer icon slots. These are host metadata fields; actual
native rendering requires separate observation.

The mascot is not the Kaijan wordmark. Preserve the original colors and
proportions. Update the source design and export again for future artwork changes;
do not redraw or modify this exported asset.
